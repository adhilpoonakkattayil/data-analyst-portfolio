 
# IPL Match Analysis & 2026 Winner Prediction

An end-to-end IPL analytics and machine learning project using historical Indian Premier League match data from Season 1 to Season 18. Python and Jupyter Notebook were used for data cleaning, season-wise preparation, and prediction, while Power BI was used to build interactive dashboards and visualize the results.

## Objective

Analyze historical IPL matches, prepare season-wise datasets, explore team performance, and use data from the 2020–2025 seasons to predict match winners for the 2026 season.

## Dataset

- **Coverage:** IPL Seasons 1–18
- **Records:** 1,169 rows in the uploaded dataset
- **Columns:** 19
- **Key fields:** Season, match date, teams, toss winner, toss decision, winner, player of the match, venue, city, match type, result, result margin, and target details.

## Project Workflow

1. **Data Cleaning:** Cleaned the historical IPL dataset and standardized team names.
2. **Season-wise Data Preparation:** Organized the data by season, separating the 18 seasons for individual analysis.
3. **Historical Analysis:** Explored match results, winning teams, player-of-the-match awards, venues, and match types.
4. **Training Data Selection:** Selected the 2020–2025 seasons for the 2026 prediction task.
5. **Machine Learning:** Developed a match-winner prediction workflow using historical match data.
6. **Prediction Output:** Generated predicted winners for IPL 2026 match combinations.
7. **Power BI Dashboard:** Created individual season pages from 2020 to 2025 and a separate Prediction 2026 page to present the results.

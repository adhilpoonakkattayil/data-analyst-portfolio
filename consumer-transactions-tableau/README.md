
# Consumer Spending Analysis | Tableau

## Project Overview
This project analyzes consumer spending patterns using Tableau.
It explores revenue, transaction volume, average spending,
product categories, locations, and payment methods.

## Objectives
- Analyze total revenue and transaction trends.
- Identify high-performing spending categories.
- Compare revenue across purchase locations.
- Understand customer payment preferences.
- Track monthly spending patterns.

## Tools Used
- Tableau Desktop
- Microsoft Excel / CSV
- Data Visualization
- Business Intelligence

## Dashboard KPIs
- Total Revenue
- Number of Transactions
- Average Spend per Transaction
- Total Quantity Sold

## Dashboard Features
- Category filter
- Payment method filter
- Top N filter
- Location filter
- Transaction date filter
- Monthly spending trend
- Spending by category
- Revenue by location
- Items by total spent
- Payment method distribution

## Dataset
File: spending_patterns_detailed.csv

The dataset is used to analyze consumer transactions,
spending amounts, purchase locations, and payment methods.
